# Pub Crawlers: dry run

## 1. Get a link (5 minutes, on the Mac)

**Option A, Netlify Drop (fastest):**

1. Go to app.netlify.com/drop.
2. Drag this whole `docs` folder onto the page. It takes about 10 seconds and you get a link like `something-random.netlify.app`.
3. Sign up (free) or claim the site when Netlify offers it. Unclaimed drops get deleted, so do this step.
4. In Site settings you can rename the link, for example to `pubcrawlers-squad.netlify.app`.

To update later, open the site in Netlify, go to Deploys, and drag the folder again. Phones pick up the new version the next time they open it with signal.

**Option B, GitHub Pages (permanent, free, uses your repo):**

1. Commit and push the `docs` folder to AKREATINEMBER/Pub_crawlers.
2. On GitHub, open Settings → Pages. Set Source to "Deploy from a branch", choose `main`, then `/docs`, and save.
3. The link is `akreatinember.github.io/Pub_crawlers/` and goes live about a minute later.

## 2. Put it on every phone (while you still have wifi)

* **iPhone:** open the link in **Safari** (not Chrome), tap Share, then "Add to Home Screen".
* **Android:** open the link in Chrome, tap ⋮, then "Add to Home screen" (or "Install app").

Then open the game **from the home-screen icon** and play from there all night. On iPhone the home-screen app keeps its own save, separate from the Safari tab, so don't switch between the two.

Open it once while you have signal. After that it opens without signal too: in a basement bar, in airplane mode, after a reload.

## 3. The 15-minute dry run (all 4 phones, at home)

Everyone picks a different class and types the same squad names in the same seat order. Then tick these off:

- [ ] **Squad code** at the top matches on all 4 phones.
- [ ] **Brew-zard:** the runes in Bag → Rune Circle show as little pixel symbols, not empty boxes.
- [ ] **Buzz:** a win vibrates the phone (Android only; iPhones don't allow vibration from web games, which is expected).
- [ ] **Mid-chug reload:** start a Stout Trial or Knight's Toast, pull down to reload (or kill the app) and reopen. The reward should still be waiting.
- [ ] **Lock screen for 5 minutes:** on unlock, the brewery has caught up with coins.
- [ ] **Airplane mode:** turn it on, close the app fully, reopen from the icon. It should load straight into your run.
- [ ] **Dim light:** turn brightness to about 30%. Can everyone still read the cards and tiles?
- [ ] **Drunk thumbs:** every button should be easy to hit one-handed with the phone held at chest height.
- [ ] **Closing Time:** on one phone, go to LOG → 🔔 CLOSING TIME, click through to the end and long-press the share card. It should save to Photos.
- [ ] **Jester:** run one Street Act; **Gambler:** one wheel spin; **Tank:** one Saga roll. Any confusing screen goes on the list.

Write down anything that felt slow, unclear or annoying, even small stuff, and send it to Claude.

## If something breaks on the night

* **Game won't open without signal:** you skipped "open it once with signal" on that phone. Use a friend's hotspot for 10 seconds.
* **Save looks wrong:** go to INFO → 📋 BACKUP / RESTORE. Early in the night, copy that code into your notes so you have a spare.
* **Totally stuck:** the plain `pubcrawlers.html` file also works on Android if you open it from Files with Chrome.
